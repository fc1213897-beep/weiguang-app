# 微光（Weiguang）README.md

## 一、项目简介

微光（Weiguang）是一款面向长期学习用户的情感陪伴型 AI 学习搭子。

产品核心并不是传统的任务管理，而是通过 AI 陪伴、轻量学习计划与情绪反馈，帮助用户缓解学习焦虑、降低孤独感，并提升长期坚持感。

微光希望成为用户在深夜学习、自我怀疑与长期奋斗过程中的一个温柔陪伴者。

**当前版本：v0.2.0** — 平衡型成长工作台（Web 优先）。产品导航收敛为五个一级心智：**今日 / 成长 / 记账 / 小光 / 我的**。详见 [`docs/PRODUCT_STATUS.md`](docs/PRODUCT_STATUS.md)。

# 三、目标用户

当前阶段主要面向：

* 考研学生
* 长期备考用户
* 自律困难用户
* 容易焦虑或孤独的学习者

---

# 四、用户核心问题

长期学习用户通常存在以下问题：

* 学习过程孤独
* 容易焦虑和内耗
* 难以长期坚持
* 缺少情绪反馈
* 传统 Todo 工具过于冷冰冰
* 完不成任务时容易产生挫败感

---

# 五、产品核心理念

微光并不是一个强调效率和 KPI 的工具。

相比于“完成多少任务”，微光更关注：

* 是否有人陪你坚持
* 是否能够降低心理压力
* 是否能让用户感受到温柔反馈
* 是否能够帮助用户长期坚持学习

# 六、当前功能（v0.2.0）

## 1. 今日 `/today`

* 今日计划与全部任务（`?mode=manage`）
* 任务打卡、快速添加、云端同步
* 备考自动生成任务；有倒计时时顶部展示距考试天数
* 完成任务后小光轻提示（非 KPI 鼓励语）

## 2. 成长 `/growth`

* **概览**：问候、今日焦点、备考与记账摘要
* **旅程**：学习阶段地图
* **统计**：热力图、周趋势、记账趋势

## 3. 记账 `/ledger`

* 记一笔、流水、日/月汇总

## 4. 小光

* 桌面全局浮动聊天入口；手机独立 Tab
* AI 对话、时段问候、备考语境陪伴

## 5. 我的 `/me`

* 账号登录 / 注册
* **备考倒计时**（可配置考试日期 + 可插拔策略生成计划）
* 偏好与关于（规划中）

## 6. 小程序

* 今日任务、记账、小光、我的（成长/备考引导 Web 配置）
* 详见 [`miniprogram/README.md`](miniprogram/README.md)

# 七、AI 人设定义（重要）

AI 不应像：

* 老师
* KPI 管理员
* 打卡监督者

而更应该像：

* 深夜一起学习的搭子
* 温柔陪伴者
* 理解焦虑的人

---

## AI 说话风格

### 正确方向

“今天先完成一个小任务就很好。”

“累的话可以慢一点，我们一点点来。”

“哪怕只是背5个单词，也是在前进。”

---

### 避免方向

“请保持自律。”

“你今天效率太低了。”

“必须完成目标。”
