# 微光产品状态（单一事实来源）

> 版本：`package.json`（当前 0.2.1）  
> 定位：**平衡型成长工作台** — 今日任务 + 小光陪伴 + 成长反馈 + 记账 + 备考配置

---

## 一级心智（Web）

| 一级 | 路由 | 用户问题 |
|------|------|----------|
| 今日 | `/today` | 今天要做什么？ |
| 成长 | `/growth` | 我走得怎么样？ |
| 记账 | `/ledger` | 花了多少钱？ |
| 小光 | 全局浮动 + `/chat` | 想聊聊 / 要鼓励？ |
| 我的 | `/me` | 账号与长期配置？ |

### 旧路由重定向

| 旧路径 | 新路径 |
|--------|--------|
| `/` | `/today` |
| `/home` | `/growth` |
| `/journey` | `/growth?tab=journey` |
| `/stats` | `/growth?tab=stats` |
| `/tasks` | `/today?mode=manage` |
| `/settings` | `/me` |

---

## 能力分层（新功能准入）

| 层级 | 定义 | 模块 | 准入规则 |
|------|------|------|----------|
| **L1 核心环** | 每天用、主闭环 | 今日任务、小光、完成反馈 | 必须先 fit「今日/小光」 |
| **L2 增强环** | 提高坚持率 | 成长 Tab、备考计划、连续天数 | 只能进「成长」或「我的」 |
| **L3 生活环** | 独立但相关 | 记账 | 独立「记账」入口 |
| **L4 平台** | 工程能力 | Auth、Supabase、小程序 API | 不进产品导航 |

---

## Web 模块地图

```
今日 /today
  ├── 今日计划（默认）
  ├── 智能拆分 / 导入清单（PC 新建计划弹窗，需登录）
  ├── 全部任务 ?mode=manage
  └── 备考任务条（有倒计时时）

小光 /chat
  ├── 陪伴聊天
  └── 对话拆分任务（如「帮我拆复习计划」）→ 一键加入今日

我的 /me
  ├── 账号
  ├── 备考倒计时
  ├── 更多功能 → 成长轨迹 / 生活记账
  └── 小程序：微信温柔提醒（每日摘要 / 添加通知，可选）
```

## 双端能力对照

| 能力 | Web 桌面 | Web 手机 | 微信小程序 |
|------|----------|----------|------------|
| 今日任务 | `/today` 侧栏 | Tab「今日任务」 | Tab「今日任务」 |
| 小光聊天 | 浮动入口 + `/chat` | Tab「小光」 | Tab「小光」 |
| 记账 | `/ledger` 侧栏 | 我的 → 生活记账 | Tab「记账」 |
| 成长（旅程/统计） | `/growth` 侧栏 | 我的 → 成长轨迹 | 我的 → 成长空间（Web 内嵌） |
| 备考倒计时 | `/me` 配置 | 我的 Tab 内配置 | 我的 → 备考计划（Web 内嵌） |
| 智能拆分任务 | PC 新建计划 / 小光聊天 | 新建计划弹层 / 聊天 | 小光聊天 |
| 清单导入 | PC 新建计划（粘贴多行） | — | — |
| 微信待办提醒 | — | — | 我的 → 温柔提醒（订阅消息） |
| 云同步 | Supabase（登录后） | 同左 | 同左 |

成长 /growth、记账 /ledger 见桌面侧栏；手机端自「我的」进入。

---

## 核心闭环

1. **今日**添加/完成任务  
2. 完成时 **小光轻提示**（非 KPI）  
3. 需要倾诉时打开 **小光聊天**  
4. 偶尔看 **成长** 回顾轨迹  
5. 长期考试在 **我的 → 备考计划** 配置，任务落在 **今日**
