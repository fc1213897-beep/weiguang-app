# 服务器上传清单（GitHub 拉不动时用）

登录失败 **404** = 服务器还没有下面这些新接口，请用 WinSCP 等方式上传到 `~/weiguang-app` 后执行 `npm run build` 和 `pm2 restart weiguang-app`。

## 必须上传的文件/目录

```
app/api/auth/wx/mp-login/route.ts
app/api/mp/tasks/route.ts
app/api/mp/tasks/[id]/route.ts
app/api/mp/chat/messages/route.ts
app/api/mp/chat/send/route.ts
app/api/chat/route.ts          （已改为共用 lib/chat-ai.ts）

lib/mp-auth.ts
lib/mp-supabase.ts
lib/mp-chat-server.ts
lib/chat-ai.ts
```

## 服务器命令

```bash
cd ~/weiguang-app
npm install
npm run build
pm2 restart weiguang-app
```

## 验证

浏览器或手机访问（把域名换成你的）：

```
http://www.weiguanglife.top:3000/api/auth/wx/mp-login
```

用 POST 会返回 400「缺少 code」——说明接口**存在**（不是 404）。

小程序在开发者工具重新**编译 → 上传**。
