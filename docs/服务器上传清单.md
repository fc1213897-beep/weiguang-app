# 服务器上传清单（GitHub 拉不动时用）

`git pull` 出现 `Connection timed out` = 服务器访问 GitHub 443 不通（国内云主机常见），**改用 WinSCP 上传**即可，不必死磕 pull。

上传后务必执行：

```bash
cd ~/weiguang-app
npm run build
pm2 restart weiguang-app
```

## 登录报错 already registered（邮箱冲突）

lib/wx-auth-server.ts

```

```
