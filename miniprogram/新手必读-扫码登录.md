# 微信扫码登录 · 零基础说明

你看到 **「页面不存在」**，是因为：  
电脑生成的小程序码在说「请打开 `pages/login/login` 这一页」，但**你微信里那个测试号小程序里还没有这一页**（或没编译上传过）。

下面用「两个项目」说明白整个流程。

---

## 一、其实有两套东西（别混在一起）

| 名字 | 是什么 | 在哪运行 |
|------|--------|----------|
| **A. 微光网页** | Next.js 项目（`weiguang-app` 根目录） | 电脑浏览器 `localhost:3000` |
| **B. 微信小程序** | 另一个独立项目（`weiguang-app/miniprogram` 文件夹） | 微信开发者工具 / 手机微信 |

- **A 负责**：生成带 `scene` 的小程序码（一张图）
- **B 负责**：用户扫码后打开的页面（`pages/login/login`）

两边必须用**同一个小程序 AppID**（你 `.env.local` 里的 `wx3a960e108120a74a`）。

---

## 二、「页面不存在」是什么意思？

生成码时，后端会告诉微信：

> 用户扫这个码后，请打开小程序里的页面：`pages/login/login`

微信去你的测试号里找这一页：

- 找到了 → 打开登录页  
- **找不到** → 就是你截图里的 **「页面不存在」**

常见原因只有三类：

1. 微信开发者工具打开的不是 `miniprogram` 文件夹（是别的空项目）  
2. 打开了 `miniprogram`，但 **从没点过「编译」**，开发版里还没有这页  
3. `app.json` 里没有登记 `pages/login/login`（本仓库已写好，复制错项目时会丢）

---

## 三、正确操作顺序（请严格按顺序做一遍）

### 第 1 步：用微信开发者工具打开「对」的项目

1. 打开 **微信开发者工具**  
2. **导入项目**（或 + 新建）  
3. 目录选：

   ```
   d:\Learn\weiguang-app\miniprogram
   ```

   **不要**选 `weiguang-app` 根目录（那是网页，不是小程序）。

4. AppID 选：**wx3a960e108120a74a**（和 `.env.local` 一致）  
5. 点确定进入项目  

左侧应能看到：

```
miniprogram/
  app.js
  app.json
  pages/login/login.js
  pages/login/login.wxml
  utils/config.js
```

### 第 2 步：先在开发者工具里能打开登录页

1. 顶部点 **「编译」**（不是预览到手机）  
2. 模拟器里应出现 **「微光 · 扫码登录」** 页面（可能提示没有 scene，黄色说明，这是正常的）  

如果编译都报错、或模拟器是空白/别的页：

- 打开 `app.json`，确认有这一行：

  ```json
  "pages": ["pages/login/login"]
  ```

- 确认 `pages/login/` 下有 4 个文件：`login.js` `login.wxml` `login.wxss` `login.json`

**这一步没成功，不要扫码。**

### 第 3 步：启动电脑网页

在 `weiguang-app` 根目录：

```bash
npm run dev
```

浏览器打开：http://localhost:3000/settings  

先访问自检：http://localhost:3000/api/auth/wx/ping  
应看到 `"ok": true`。

### 第 4 步：电脑生成小程序码

在设置页点 **「微信扫码登录」**，出现一张 **小程序码**（不是普通网址二维码）。

### 第 5 步：用手机微信扫「电脑上」的码

- 用 **微信扫浏览器里那张小程序码**  
- 或开发者工具菜单 **预览** → 用手机扫预览码（也可以）  

扫成功后应进入 **登录页**，且带有 scene（不再显示「页面不存在」）。

### 第 6 步：在小程序里点「允许登录」

电脑网页会自动登录。

---

## 四、不要这样做（很容易踩坑）

| 错误做法 | 结果 |
|----------|------|
| 只点开发者工具「编译」进登录页，不扫电脑上的码 | 提示「未获取 scene」 |
| 小程序项目和网页不是同一个 AppID | 页面不存在或登录失败 |
| 在「别的」小程序项目里做了 login 页，但电脑 `.env` 仍是 wxff782… | 码指向的 AppID 里没有你的页面 |
| 没编译就先扫电脑上的码 | 页面不存在 |

---

## 五、如果你已经在「自己的」小程序里做了 login 页

若登录页路径**不是** `pages/login/login`，而是例如 `pages/index/index`：

1. 改电脑 `.env.local`：

   ```env
   WX_MP_LOGIN_PAGE=pages/index/index
   ```

2. **重启** `npm run dev`  

3. 重新在网页点「微信扫码登录」生成**新码**再扫  

路径必须和该小程序 `app.json` 里 `pages` 数组中的某一项**完全一致**（不要带 `.wxml`，不要开头 `/`）。

## 七、还是「页面不存在」时自查清单

- [ ] 开发者工具项目目录是 `...\weiguang-app\miniprogram`  
- [ ] AppID = `wx3a960e108120a74a`  
- [ ] 点「编译」后模拟器能进登录页  
- [ ] `.env.local` 里 `WX_MP_LOGIN_PAGE=pages/login/login`  
- [ ] 扫的是 **设置页生成的小程序码**，不是随便一个码  
- [ ] `npm run dev` 正在运行  

做完第 1～2 步后，把开发者工具 **编译结果**（成功或报错截图）发出来，可以继续帮你对。
